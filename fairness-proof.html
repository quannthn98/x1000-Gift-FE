How It Works

1. Server Seed Generation

Before the game starts, the server generates a random seed and shares its hash with you. The actual seed remains hidden until after the game.

2. Client Seed

Your device generates a random client seed that contributes to the final outcome. This ensures the server cannot predict or manipulate the result.

3. Nonce

A unique number (nonce) is assigned to each game to ensure every result is unique, even with the same seeds.

4. Result Calculation

The server seed, client seed, and nonce are combined and hashed using SHA-256. This hash is converted to determine the game outcome (Heads or Tails).

5. Verification

After the game, the server reveals the original seed. You can verify that the hash matches and recalculate the result yourself to confirm fairness.

Manual Verification

Want to verify the result yourself? Use any SHA-256 calculator and follow these steps:

  1. Concatenate: ServerSeed + ClientSeed + Nonce
  2. Calculate SHA-256 hash of the concatenated string
  3. Convert first 8 characters of hash to decimal
  4. Divide by 0xFFFFFFFF to get value between 0-1
  5. If value < 0.5: Heads, else: Tails
